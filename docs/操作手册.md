# Web Basic Admin · 操作手册

> 面向使用者：怎么登录、每个菜单能做什么、遇到问题怎么处理。
> 二次开发请看 [开发手册](./开发手册.md)。

---

## 1. 登录与账号

### 1.1 登录

1. 打开系统地址，输入账号与密码。
2. 按系统配置，可能需要填图形验证码、拖动滑块（两者都能被管理员在「站点设置」里关闭）。
3. 忘记密码请联系管理员重置；连续输错会触发锁定（默认 5 次锁定 10 分钟）。

### 1.2 密码规则（设置/修改密码时必须满足）

- 至少 **8 位**；
- 必须同时包含**大写字母、小写字母、数字**；
- 不能是常见弱口令（如 `12345678`、`password`、`admin123`）；
- 不能出现 3 个及以上连续相同的字符（如 `aaa`、`111`）。

页面会直接提示还缺什么，不用反复试。修改成功后当前账号所有登录状态失效，需要用新密码重新登录。

### 1.3 锁屏与退出

- 右上角头像 → **锁定屏幕**：临时离开时锁屏，输入密码解锁（不退出登录）。
- 右上角头像 → **退出登录**：清空会话，回到登录页（服务端会同步吊销当前会话）。

### 1.4 个人中心

右上角头像 → 个人中心：

- **头像**：鼠标移到头像上或点「上传头像」选图，上传后点「保存」生效，右上角头像同步更新。
- **资料**：昵称、性别、邮箱、手机号，保存后立即生效。
- **修改密码**：见 §1.2。

### 1.5 使用文档

右上角头像 → **使用文档**：弹出内置说明窗口（快速开始、工作台、密码规则、常见问题），不需要另开页面。

## 2. 工作台

首页即工作台：

- **顶部 4 张卡片**：用户总数、角色/部门、文件总量、今日登录（含在线会话与今日操作数）。
- **下方页签**：三个页签在同一个卡片里切换，不用跳页面：

| 页签 | 能做什么 |
| --- | --- |
| 我的待办 | 新建（标题 / 优先级 / 截止时间 / 业务链接）、完成、恢复、删除；逾期标红；「查看业务」跳回业务单据 |
| 我的消息 | 查看站内信、标记已读、全部已读、删除；点标题看详情 |
| 通知公告 | 管理员发布的公告，点标题看详情并自动标记已读 |

- **顶栏铃铛**：显示通知 / 消息 / 待办三类未读数，点条目或「查看全部」直接跳到工作台对应页签。

## 3. 组织与权限

### 3.1 用户管理

- 新增用户：账号、昵称、部门、角色、初始密码（留空自动生成强密码）。
- 列表支持搜索、启用/停用、重置密码、删除；重置后的密码只显示一次，请及时记录。
- 「更多」菜单里还可以重置密码、查看详情。

### 3.2 角色管理

- 角色绑定「菜单权限」：勾选哪些菜单与按钮，用户登录后就能看到/操作哪些。
- 数据权限：全部 / 本部门 / 本部门及以下 / 仅本人 / 自定义部门。
- 权限变更后，相关用户需要重新登录（或刷新页面）才生效。

### 3.3 菜单管理

- 目录、页面、按钮、接口四类节点；页面的「权限标识」同时是后端接口的校验码。
- 自定义菜单要填写「组件路径」（如 `system/user/index`，对应前端页面文件）。

### 3.4 部门与岗位

- 部门是树形结构，用户挂到部门上，数据权限依赖它。
- 岗位用于标识职责，可被用户引用。

## 4. 系统设置

### 4.1 站点设置（个性化配置）

保存后登录页与浏览器标题立即生效：

| 配置项 | 说明 |
| --- | --- |
| 网站名称 | 登录页标题、浏览器标签标题、顶栏品牌名 |
| 站点 logo | 建议 1:1 透明底 PNG/SVG，≤ 2MB |
| 登录页背景图 | 建议 1920×1080，≤ 2MB；留空用默认插画 |
| 登录页描述 / 副标题 | 登录页左侧大标题与下方说明，留空用默认文案 |
| 开放注册 | 关闭后登录页隐藏注册入口，注册路由不可达 |
| 图形验证码 | 关闭后登录不再要求输入图片验证码 |
| 滑块校验 | 关闭后无需拖动滑块，直接点「登录」 |

右侧提供效果预览；改完刷新登录页即可看到变化，无需重启服务。

> 验证码是防撞库的最后一道防线，只有在内网或已接单点登录时才建议关闭。

### 4.2 字典管理

- 左侧字典类型（如「用户性别」），右侧字典项（标签 / 键值 / 排序 / 标签样式 / 状态）。
- 下拉框、状态标签全站统一取字典，改字典即全站生效。

### 4.3 参数配置

键值型参数（上传大小限制、是否多租户等），部分参数以公开接口暴露给前端（如登录开关）。

### 4.4 租户管理

- 每个租户有独立的数据空间与默认部门；用户登录后自动带入所属租户。
- 列表查询自动按租户过滤，管理员不需要手动筛。

### 4.5 文件管理

- 上传：默认最大 20MB，白名单包含图片、PDF、Office、压缩包、txt、mp4。
- 存储：本地磁盘（`/static` 访问）或阿里云 OSS（可私有读 + 签名 URL）。
- 目录：文件按上传日期自动分目录（`年/月/日/业务/`），文件名带日期时间；
  列表上方可用「今天 / 近 7 天 / 本月」或自定义日期区间快速定位，「存储目录」列可直观看到位置。
- 上传方式（自动选择）：配置为 OSS 时浏览器直传（省带宽）；本地磁盘或直传失败时经服务端中转。
  OSS 直传需要运维在 Bucket 上配置 CORS。

### 4.6 定时任务

三种执行方式，调度策略（cron / 超时 / 重试 / 启停）通用：

| 类型 | 执行内容 | 适合做什么 |
| --- | --- | --- |
| 内置处理器 | 程序里已实现的维护动作（清会话、清日志…） | 系统自身定期维护 |
| HTTP 调用 | 你填的回调地址 + 方法 | 定时触发第三方系统 |
| Shell 脚本 | 在线填写的 sh/bash/python 脚本 | 自定义运维脚本、数据处理 |

- Shell 类型默认关闭：需要运维在配置里打开 `scheduler.shell_enabled`，否则新增时该类型置灰。
- 支持「立即执行一次」、启用/停用、查看执行日志（含脚本输出）。
- 多副本部署时通过租约保证同一时刻只有一台执行。

### 4.7 通知公告管理

- 起草 → 发布（发布时给本租户所有启用用户扇出站内信）→ 关闭。
- 已关闭的公告不能再修改，避免「发出去的公告被静默篡改」。
- 普通用户在「工作台 → 通知公告」页签里查看。

### 4.8 消息与待办（推送）

- **推送站内信**：选择接收人（不选=全员）、标题、内容、类型；可选「幂等键」，同键重复提交不会重复推送。
- **派发待办**：选择负责人、标题、优先级、截止时间、业务链接；同样支持幂等键。
- 页面也是业务系统对接的调试入口（外部系统调用 `POST /api/v1/open/messages`、`/open/todos`）。

### 4.9 代码生成

- 选择数据库表 → 预览生成的 Go 实体/服务/接口、Vue 页面、SQL 菜单脚本 → 打包下载。
- 生成结果按本脚手架的约定产出，复制进项目即可继续开发。

## 5. Docker 管理

> 详细原理与限制见 [Docker管理.md](./Docker管理.md)。

### 5.1 环境管理

- 首次启动会自动登记「本地 Docker」；Windows 使用 npipe，Linux/macOS 使用 `/var/run/docker.sock`。
- 「新增环境」支持：
  - **本地 Socket**：一般留空自动探测；
  - **远程 TCP**：如 `192.168.1.10:2375`；
  - **远程 TLS**：主机 + CA + 客户端证书 + 私钥（默认 2376）；
  - **SSH**：主机、用户、密码或私钥、远端 Socket（默认 `/var/run/docker.sock`）。
- 保存后点「测试」验证连通性；离线环境会在列表显示红色状态与错误原因。
- 「设为默认」决定页面首次打开时选中的环境。
- 环境凭据加密存储在独立 SQLite，编辑时留空表示保持原值。

### 5.2 容器 / 镜像 / 网络 / 数据卷

| 页面 | 常用操作 |
| --- | --- |
| 容器 | 搜索/状态筛选；启动、停止、重启；日志（可调 tail）；资源快照；命令执行；详情；删除；创建容器（端口/环境变量/挂载/网络/重启策略）；清理已停止 |
| 镜像 | 搜索、包含中间层、流式拉取（显示进度）、删除、清理悬空镜像、inspect |
| 网络 | 创建（bridge/overlay、子网/网关）、接入/断开容器、删除、清理未使用 |
| 数据卷 | 创建（驱动/参数）、删除、清理未使用、inspect |

- 容器「命令」为非交互式 `/bin/sh -c`，最长 60 秒；适合诊断，不是登录终端。
- 删除正在被容器使用的镜像/网络/卷会失败，请先处理依赖。
- 数据卷「清理未使用」不可恢复，操作前确认。

### 5.3 Stack

- 「新建 Stack」进入编辑器，填写名称、选择环境与类型：
  - **Docker Compose（单机）**：在所选 Docker 主机创建容器；
  - **Docker Swarm Stack**：需要环境已初始化 Swarm 且当前是管理节点。
- 编辑器分两个页签：`docker-compose.yml` 与 `.env`（变量插值）；保存即写入 SQLite 并生成历史版本。
- 「保存并部署」会保存后立即部署；「仅部署」使用当前已保存内容。
- 列表显示运行态（容器/服务 running/total）、最近部署时间与「未部署变更」。
- 详情抽屉可查看运行资源、历史版本（可回滚并部署）、操作记录、compose 文件。
- 删除 Stack 时可选择：
  - 同时删除运行资源（容器/服务/网络）；
  - 并删除数据卷（不可恢复）。
- 导入/导出：导出 JSON 含环境名称与 compose 内容；导入按环境名称匹配，可选覆盖同名 Stack。
- 下载 SQLite 备份：仅超级管理员，用于整库恢复。

**编写提示**：

- 绑定挂载必须写宿主机绝对路径，如 `/data/app:/app/data`；
- 单机 Compose 不支持 `build`、`env_file`、`secrets/configs`、端口范围；
- Swarm 的 secret/config 只支持 `external: true`，请先在「Swarm 集群 → 密钥/配置」创建同名对象；
- 不支持在 Web 端上传构建上下文，请先构建镜像并 push 到仓库。

### 5.4 Swarm 集群

| 页面 | 内容 |
| --- | --- |
| 集群状态 | 初始化/退出 Swarm，查看集群 ID、节点数、管理节点数 |
| 节点 | 角色（manager/worker）、可用性（active/pause/drain）、标签、移除 |
| 服务 | 创建/编辑、镜像/副本/端口/环境变量/约束、扩缩容、日志、详情、删除 |
| 任务 | 任务状态、所属服务/节点、错误信息 |
| 密钥/配置 | 创建与删除；内容只提交给 Docker，不在本系统保存明文 |

- 停止 Swarm Stack 会把 replicated 服务副本数置 0；global 服务不支持停止，请直接删除 Stack。
- 管理节点才能部署服务/Stack；工作节点只能查看。

### 5.5 资源授权

- 「资源授权」页面按环境把角色/用户加入授权列表，选择级别：
  - **只读**：查看资源；
  - **操作**：启停/部署/变更资源；
  - **管理**：修改环境与授权。
- 功能权限（角色管理里勾选的 Docker 菜单/按钮）与环境资源授权必须同时满足。
- 超级管理员默认拥有全部环境，不需要授权。
- 非超级管理员创建环境后自动获得该环境管理权限。

### 5.6 备份与恢复

1. 「堆栈 → 下载 SQLite 备份」得到 `.db`；或停服复制 `data/tomato-docker.db`。
2. 同时保存 `configs/config.yaml` 中的 `jwt.secret`（解密环境凭据）。
3. 恢复：停服放回 `.db`，保持 JWT secret 一致，启动即可。
4. 只迁移 Stack 时可用「导出/导入」JSON；环境需要先创建。

## 8. 常见问题

| 现象 | 原因与处理 |
| --- | --- |
| 登录提示验证码错误 | 验证码一次性使用，刷新页面重新获取；多次失败请稍后再试 |
| 登录提示账号锁定 | 连续失败触发锁定，等待锁定时间结束或联系管理员解锁 |
| 改密码提示「还需要包含大写字母」 | 密码规则未满足，按提示补齐即可（§1.2） |
| 保存后只弹一次提示 | 正常现象：成功提示统一由接口层给出 |
| 看不到某个菜单 | 角色未勾选该菜单权限；让管理员授权后重新登录 |
| 上传大文件很慢 | 让运维把存储切到 OSS 并配置 CORS，浏览器会直传 |
| 找不到以前上传的文件 | 文件按日期分目录存放，用列表上方的日期筛选或「存储目录」列定位 |
| 操作日志里看到两条相同记录 | 一条是业务操作、一条是后台任务触发，可按「操作人」区分 |
| 页面数据没更新 | 点右上角刷新按钮，或重新进入该页签 |
| 工作台卡片一直转圈 | 概览接口较慢（在线用户很多时更明显）。系统已改为批量查询，若仍长时间转圈请点「重新加载」并联系管理员查看服务状态 |
| Docker 环境显示离线 | 检查 Docker 服务是否启动、Socket/端口是否可达、TLS 证书是否过期；点「测试」查看具体错误 |
| 看不到 Docker 环境 | 当前账号没有被授予该环境：让管理员在「Docker 管理 → 资源授权」中授权，并确认角色已勾选 Docker 功能权限 |
| 部署 Stack 很慢/超时 | 首次拉镜像可能数分钟；部署请求前端超时 20 分钟，请耐心等待。若失败看 Stack 详情里的操作记录与状态说明 |
| Stack 部署报「secrets/configs 不支持」 | 单机 Compose 请改用 environment；Swarm 请先创建 external 密钥/配置并在 compose 中声明 `external: true` |
| 绑定挂载报「不是绝对路径」 | 改成宿主机绝对路径，如 `/data/app:/app/data`（Windows 容器路径也需写绝对路径） |
| 修改环境后连接失败 | 编辑时留空凭据表示保持原值；如果勾选了「清空凭据」，需要重新填写 TLS/SSH 凭据 |
| 迁移后 Docker 凭据解密失败 | 新机器的 `jwt.secret` 与备份时不一致；改回原密钥，或重新录入环境凭据 |
